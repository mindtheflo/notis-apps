# Skills Graph

See how your installed skills reference one another.

## What is included

- Interactive pan-and-zoom skill map
- Incoming and outgoing references with evidence
- Link table, clusters and standalone skills

## Get started

Install the app and run **skills-graph-onboarding** in any assistant connected to your Notis account through MCP or the CLI. All required app skills and their supporting files are bundled. You can start empty or choose the clearly fictional examples. Optional connections and automations are configured for your own account; nothing sends or schedules automatically.

## Your data

Your records stay in your own Notis workspace. Store screenshots and bundled examples are wholly fictional, never publisher records. Example datasets are optional and deduplicated during onboarding. Existing personal data is preserved.

## Help

Use the bundled onboarding skill to review setup, source access or missing data. The app supports light and dark themes and desktop and phone layouts.
